# 🚀 Jerin J — Personal Portfolio

An ultra-modern, high-performance personal portfolio engineered with a sleek AI Cyberpunk aesthetic, smooth micro-interactions, and instant page-load performance.

## ✨ Key Features

- **⚡ Blazing Fast Performance:** Preconnected fonts, lazy-loaded media, and near-instant (<250ms) preloader dismissal.
- **🛰️ Dynamic Top Scroll Line:** GPU-composited 60 FPS laser progress beam gliding from left to right as you scroll down.
- **🌌 Cyber Quantum Theme Switcher:** Live theme engine with Quantum Warp pulse transitions (Cyber Neon, Neural Emerald, and Quantum Violet).
- **📂 Live GitHub Repository Explorer:** Terminal mock file-tree leveraging GitHub REST API to browse repositories and highlight code dynamically.
- **🎓 Interactive Certificate Showcase:** Interactive credential modal with responsive preview and download capabilities.
- **💎 Design System:** Custom glassmorphism, responsive tilt micro-interactions, and mobile-first typography.

## 🛠️ Built With

- **HTML5** — Semantic, SEO-optimized markup
- **Vanilla CSS3** — Modular tokens, glassmorphic UI, GPU-accelerated transforms
- **Vanilla JavaScript (ES6+)** — Asynchronous API integrations, `requestAnimationFrame` scroll tracking
- **GitHub REST API** — Dynamic file hierarchy and source code viewer
